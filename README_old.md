# Customer Service
Spring Boot microservice with **Web**, **Actuator**, **Spring Data JPA**, **PostgreSQL**, **Lombok**, and **OpenAPI (Swagger UI)**. Built on **Spring Boot 3.3.4** and **Java 20**.
## Run
1. Create DB/schema in PostgreSQL; update `application.yml` creds.
2. Start: `mvn spring-boot:run`
3. Swagger: http://localhost:8081/swagger-ui.html , Health: /actuator/health
